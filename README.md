# Prévia — simulador da reforma tributária para escritórios de contabilidade

Página estática publicada no GitHub Pages para colher opinião de contadores antes do lançamento.
Não vende nada: mostra o que a reforma faz com a carteira de um escritório e pergunta se aquilo
seria útil.

As empresas e os valores são fictícios; os números foram calculados pelo simulador, com a versão 0.1
dos parâmetros da reforma (ainda estimados, sem alíquota fechada em lei complementar).

Gerado a partir do build do produto (`scripts/gerar-oferta.mjs`), que também remove os blocos
marcados como oferta comercial. Não editar à mão: qualquer ajuste de texto se faz no produto e gera
de novo.

# Prévia — simulador da reforma tributária para escritórios de contabilidade

Páginas estáticas publicadas no GitHub Pages para colher opinião de contadores antes do lançamento.

- `index.html` — a oferta.
- `demonstracao.html` — a conta de uma empresa fictícia, do cadastro ao relatório.

As empresas e os valores são fictícios; os números foram calculados pelo simulador, com a versão 0.1
dos parâmetros da reforma (ainda estimados, sem alíquota fechada em lei complementar).

Estes arquivos são gerados a partir do build do produto (`scripts/gerar-oferta.mjs`), não editados
à mão: qualquer ajuste de texto se faz no produto e gera de novo.
